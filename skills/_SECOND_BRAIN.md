## Content Template

```markdown
### [Tool/Concept Name]

Brief description (1-2 lines).

| Aspect | Detail |
|--------|--------|
| **What** | Core functionality |
| **Why** | Key benefit |

- [Source](url) - YYYY-MM-DD
```

For reference-only: `- [Title](url) - Brief description`

## Timeline Entry

```markdown
- **YYYY-MM-DD** | [Topic] | Source: [Newsletter/Email/Clipping] | -> Second Brain - [File].md
```

Add to `Second Brain - Timeline.md` for every integration.

## Rules

1. **Quality over quantity** - only actionable content goes to Second Brain
2. **Be concise** - distill to key insights, not full summaries
3. **Preserve sources** - always include URL and date
4. **No duplication** - check if topic already exists before adding
5. **Ask if unclear** - ambiguous categorization -> ask user
